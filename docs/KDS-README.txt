Kitchen Display + Order Routing deployment

After this feature is merged:
1. Deploy the newest main branch build.
2. Visit /upgrade.php.
3. Click Run Gelato Upgrade.
4. Open /kds.php with an owner or operational manager account.
5. Create active kitchen stations and map menu items to stations before live service.

Unmapped menu items are intentionally retained in the Unrouted queue and cannot begin preparation until assigned.
