# FM-G8D2A — Participant Timeline and Chat Folder

Authenticated, scoped participant history with server timestamps. Events record high-level operational actions only; never raw images, speaker features, PINs or conversation text.

The Agent workspace keeps using the existing private Agent Chat engine and thread ownership. A participant may explicitly bookmark their existing Agent Chat thread in their own folder. Managers can see an employee's operational onboarding status and goal progress, but not that employee's private chat folder or conversation contents.

FM-G8D2A provides a read-only, permission-filtered summary for the main Agent Brain. Specialist sub-agent scheduling and governed research tasks are a separate next section, FM-G8D2B, gated on this section's merge.

Apply protected upgrade.php after deployment. Live database integration requires installed-site verification.
